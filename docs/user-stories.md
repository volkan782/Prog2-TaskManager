# User stories
1. As a student, I want to create a regular task so that I can remember homework.
2. As a student, I want to mark important tasks urgent so that I can prioritize them.
3. As a student, I want to list tasks by priority or title so that I can plan my work.
4. As a student, I want to mark tasks complete or remove them so that I can track progress.
5. As a student, I want my tasks saved between runs so that I do not lose my plan.

# Acceptance examples
- Adding an urgent and a regular task, then listing by priority, displays urgent first.
- Completing a task changes its displayed state to DONE.
- Restarting the application restores previously saved tasks.
- An invalid ID or blank title shows an error without terminating the program.
